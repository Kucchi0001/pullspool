# PullSpool 视觉与交互规范（Soft Modern 版）

> 2026-11 改版。定位：**Soft Modern × Premium Minimalism × Professional Utility**。
> 这是一套完整的视觉体系，不是"换颜色 + 加圆角"。所有颜色、圆角、阴影都必须来自
> `frontend/src/styles/tokens.css`，组件里不允许出现裸色值。

---

## 1. 设计原则

1. **冷静而克制**：冷调紫灰底色、纯白表面、深靛侧栏，避免暖黄与纯黑。
2. **下载优先**：任务与取回是视觉中心；系统监控降级为紧凑状态块。
3. **柔和层次**：低对比边框 + 轻微色差 + 克制阴影，不使用玻璃拟态、霓虹、强渐变。
4. **一致材质**：哑光平面为主，圆角分三级（控件 8–10、卡片 14–18、浮层 22）；
   唯一的 3D 材质是品牌图标本身。
5. **安静交互**：180–280ms、以透明度和位移为主，尊重 `prefers-reduced-motion`。
6. **真实数据**：空状态、稀疏数据也要好看；不为截图伪造数据。

参考气质：macOS 应用的留白、独立开发者工具的密度、冷调纸感的触感。禁止传统
Bootstrap Admin 的"白底蓝条 + 四张同构卡片"。

### 2.4 图标使用边界

- 内容区**不用装饰性图标**：KPI、文件列表、设置分区标题、空状态一律不放图标或彩色图标底。
- 图标只保留在真正承担功能的地方：侧栏导航、搜索、复制、关闭、行内操作、状态小圆点。
- 优先级：文字 > 数字 > 排版层级 > 图标。能靠字号、字重、留白和分隔线说清的，不用图标。
- 不新增图标字体、彩色图标底板或大面积 pastel 色块；品牌 3D 图是唯一例外。

## 3. 字体与排版

### 3.1 字体

```css
--font-sans: "Inter Variable", "Inter", -apple-system, BlinkMacSystemFont,
  "Segoe UI", "PingFang SC", "Hiragino Sans GB", "Microsoft YaHei", sans-serif;
--font-mono: "SFMono-Regular", ui-monospace, "Cascadia Mono", Menlo, Consolas, monospace;
```

Inter 通过 `@fontsource-variable/inter` 自托管（无外网字体请求），中文回退到系统
苹方/微软雅黑。数字统一启用 `font-variant-numeric: tabular-nums`。

### 3.2 字号阶梯

| Token | 字号/行高 | 用途 |
|---|---|---|
| `--fs-page` | 22 / 28 | 页面标题 |
| `--fs-section` | 15 / 22 | 面板标题 |
| `--fs-body` | 14 / 21 | 正文、表格主文字 |
| `--fs-sm` | 13 / 19 | 次要正文、按钮 |
| `--fs-xs` | 11.5 / 16 | 元信息、标签 |
| `--fs-kpi` | 30 / 34 | 统计数字 |
| `--fs-label` | 11 / 14 | 全大写小标签（字距 0.055em） |

标题使用负字距（-0.022em），小标签使用正字距；中文文案不使用全大写。

### 3.3 数字格式

- 文件大小：`1.2 GB`、`577 B`，保留一位小数，单位大写 B/KB/MB/GB/TB。
- **流量统计统一用 MB**：图表轴、今日/本月汇总、悬浮提示、KPI 全部显示 `0 MB` / `50 MB` / `1,229 MB`，
  不出现 `B`、`KB`；避免同一面板混用多套单位。
- 速度：`8.4 MB/s`；剩余时间：`12 分 30 秒`；日期：`11-26 22:09`。
- 统计数字与时间列右对齐，启用 tabular numbers。

## 5. 布局

### 5.1 结构

```
┌──────────────┬────────────────────────────────────────────┐
│ 深色侧栏 248 │ 顶栏 64：页面标题 · 实时状态 · 刷新          │
│ Logo/CTA     ├────────────────────────────────────────────┤
│ 导航         │ 内容区（最大 1440，居中，32 内边距）        │
│ 主题/用户    │                                            │
└──────────────┴────────────────────────────────────────────┘
```

- 侧栏：248px；1180px 以下收为 72px 图标栏；767px 以下变为抽屉 + 底部导航。
- 顶栏：64px（移动 58），canvas 半透明 + 12px 模糊，底部 1px 细分隔线。
- 内容：`max-width: 1440px`；2K（≥2200）2000px、3K（≥3000）2400px、4K（≥3600）2800px；
  `padding: 24px 32px 48px`，大屏按页边距 48/64/72px 放大；移动 `16px`，底部留 92px 给导航。
- 页面不出现横向滚动；移动端卡片列表替代表格。

### 5.2 断点与行为

| 断点 | 行为 |
|---|---|
| ≥3600（4K） | 内容 2800px；侧栏 304px；正文 17px；表格列按比例展开；登录卡 620px |
| 3000–3599（3K/4K 缩放） | 内容 2400px；侧栏 288px；正文 16px；登录卡 560px |
| 2200–2999（2K） | 内容 2000px；侧栏 272px；正文 15px；表格列按比例展开；登录卡 500px |
| 1440–2199 | 完整侧栏；内容上限 1440px；总览双列（1.9fr / 1fr）；流量图通栏 |
| 1280–1439 | 完整侧栏；内容随视口收缩；总览双列 |
| 1024–1279 | 侧栏 72px 图标；总览单列；系统/流量并排为两列 |
| 768–1023 | 统计改为 2×2；表格隐藏部分列（速度/创建时间/SHA） |
| ≤767 | 侧栏抽屉；底部导航；表格转卡片；抽屉转为底部 Sheet |

---

### 5.3 对齐规则（强制）

- 面板内边距统一 --panel-inset: 24px（移动 16px），页头、表头、行、表单同一边缘。
- 面板之间的间距统一 16px；统计轨与下方内容的间距同样 16px。
- 页面标题、顶栏右侧操作与内容区共享同一 `--content-max` 与 `--page-pad`
  （1440/32、2K 2000/48、3K 2400/64、4K 2800/72）；标题必须与内容左边缘重合。
- 表格 header 与 row 使用同一 grid-template-columns 和同样的左右 padding。
- 数值列右对齐并启用 tabular numbers；操作列右对齐。
- 图标与文字间距 8–12px，不得凭感觉微调。

## 6. 组件规范

### 6.1 按钮（`UiButton`）

| 类型 | 样式 | 高度 |
|---|---|---|
| primary | 靛蓝实底 + 白/深色对比文字 | 36（sm 30） |
| secondary | 象牙白底 + 1px 边框 | 36 |
| ghost | 透明，悬停浅底 | 36 |
| danger | 浅红底 + 红字（确认类操作） | 36 |

悬停只变背景/边框，按下 `scale(0.985)`；禁用统一浅底灰字、保留边框，不使用低透明度。
所有按钮必须有 `:focus-visible` 外圈（2px accent）。

### 6.2 输入框

高 38（登录/改密 42），圆角 10，`--bg-raised` 底，1px 边框；聚焦时边框 accent +
3px 柔光环。标签在上，辅助说明 11.5px 三级文字。

### 6.3 状态标签（`StatusBadge`）

胶囊形，高 22，5px 圆点 + 11px 文字；背景为对应语义浅底。映射：

- 下载中 / 校验中 / 回传中 → accent
- 等待取回 / 已取回 → success
- 等待中 / 已暂停 / 已删除 / 已取消 → neutral
- 已过期清理 → warning
- 下载失败 → danger

### 6.4 进度条

高 4–5px，胶囊；槽为 `--bg-subtle` + 1px 内描边；下载中 accent、完成 success、
失败 danger、暂停/排队 neutral 55%。宽度变化 500ms；未知进度用 38% 滑块动画。

### 6.5 表格

- 表头 44px，11px 三级文字，字距 0.02em，sticky 于顶栏之下；
- 行高 56（紧凑 44），行间只用 `--border-subtle` 分隔；
- 主列：文件名 13.5px 中等 + 主机名 11.5px 三级；不放文件类型图标；
- 操作按钮 30px 方形，默认 72% 不透明度，行悬停升到 100%；
- 行悬停背景为 65% 的 `--bg-hover`，不做整行阴影；
- 底部 42px 页脚显示任务总数与状态汇总。

### 6.6 弹窗 / 抽屉 / Toast

- 弹窗：宽 460，圆角 22，遮罩 42% + 3px 模糊，进入 8px 上移 + 0.98 缩放。
- 新建下载抽屉：宽 440，右侧滑入；移动端为底部 Sheet（最大 92dvh，顶部抓取条）。
- Toast：右上浮层（移动在底部导航上方），圆角 14，图标底色区分语义，200ms 淡入。

## 7. 页面设计

### 7.1 总览

1. **统计轨**：一个面板内四段，不拆成四张同构卡片；每段 11.5px 标签 +
   30px 数字 + 辅助行，段间细分隔线，不放图标。第三段带存储进度。
2. **正在下载**（视觉中心）：文件名 + 状态/速度/剩余时间 + 右侧进度与
   百分比；空状态只留文字与"新建下载"。
3. **最近可取回**：文件管理器质感，文件名 + 大小/完成时间 + 浅靛蓝"取回"按钮。
4. **引擎与存储**：紧凑卡片，突出引擎状态、出口 IP、防火墙、队列；CPU/内存/磁盘改为
   三行细进度，不抢主区。
5. **近 14 天流量**：通栏，左侧双系列折线/面积图（单位 MB，带网格、悬浮提示），
   右侧今日/本月汇总 + 统计口径说明。

### 7.2 下载

搜索 + 状态筛选 + 新建（桌面由侧栏 CTA 承担，窄屏才显示工具栏按钮）；表格含
名称/主机、大小、状态、进度、速度、剩余、创建时间、操作；底部页脚统计。

### 7.3 等待取回

顶部提示条（浅靛蓝）+ 汇总 + 批量"确认取回并删除"；表格展示 SHA-256 胶囊、完成时间、
有效期倒计时；取回为主操作，复制链接/确认删除为次级操作。移动端卡片保留复选框。

### 7.4 历史

说明条 + 状态筛选 + 只读表格：大小、状态、SHA、下载/回传字节、时间。

### 7.5 设置

按"下载 / 存储与清理 / 安全 / 界面 / 关于"分区；分区标题只留文字，不放图标；
两列表单，未保存时底部浮动保存条（模糊背景、圆角、阴影）。安全区先提供
「登录用户名」修改（需当前密码确认），再提供密码修改。

### 7.6 登录 / 改密

冷调紫灰画布 + 极淡品牌径向光晕；400px 纯白卡片、56px 高透明品牌 Logo；输入 42px；
登录按钮通栏；脚注说明初始密码位置。移动端保持卡片，不做全屏透明化。

### 7.7 新建下载

全局可达（侧栏 CTA、下载页、空状态）。字段：链接（等宽字体）、可选文件名、
高级选项（连接数、限速）；错误在表单内显示，不使用 alert。

## 8. 动效

| 场景 | 实现 | 时长/曲线 |
|---|---|---|
| 页面切换 | `.view` 上移淡入 | 280ms |
| 面板入场 | `.reveal` 依次上移淡入（55ms 阶梯） | 440ms |
| 列表行 | `.row-in` 上移淡入（40–45ms 阶梯） | 340ms |
| 统计数字变化 | `value-in` 轻微上移淡入 | 220ms |
| 侧栏选中条 | `scaleY` 展开 | 200ms |
| 实时状态点 | 呼吸光环 | 2.6s 循环 |
| 悬停/按钮 | 背景/边框/位移 | 180ms |
| 抽屉 | 位移 + 遮罩 | 280ms + 200ms |
| 弹窗 | 上移 + 缩放 | 220ms |
| 进度 | 宽度过渡 | 500ms |
| Toast | 淡入 + 位移 | 200ms + 240ms |
| 主题切换 | 背景/边框/文字颜色过渡 | 220ms |

动效只用于表达层级与状态变化，不做连续装饰动画；`prefers-reduced-motion` 下压缩为 0.01ms。

## 9. 可访问性

- 文本对比度：主文字 ≥ 7:1，次级 ≥ 4.5:1（两套主题均验证）。
- 所有交互元素可键盘到达，focus 外圈可见；跳过链接直达主内容。
- 状态不只靠颜色：标签带文字，进度条有 `role="progressbar"` 与 aria 值。
- 图标按钮必须有 `aria-label`/`title`。
- 移动端触控目标 ≥ 30×30px（主要按钮 36）。

---

## 10. 中文文案

- 句子简短、主动语态；不使用感叹号。
- 失败信息给"发生了什么 + 下一步"，不暴露引擎原始英文（原始信息放 title 供排查）。
- 统一术语：下载 / 等待取回 / 取回 / 确认取回并删除 / 临时存储 / 回传。
- 统计口径必须标注"应用层统计，不等于运营商计费"。
