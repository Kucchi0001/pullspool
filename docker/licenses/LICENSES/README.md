# License texts

This directory contains the full license texts for PullSpool's third-party
components. See [../THIRD_PARTY_NOTICES.md](../THIRD_PARTY_NOTICES.md) for the
component-to-license mapping and upstream source links.

| File | Used by |
|---|---|
| `MIT.txt` | PullSpool and MIT-licensed dependencies |
| `Apache-2.0.txt` | Caddy, aiohttp, OpenSSL, tzdata, OpenTelemetry, and other Apache-2.0 dependencies |
| `GPL-2.0.txt` | aria2, BusyBox, iptables, apk-tools |
| `OFL-1.1.txt` | Inter font |
| `ISC.txt` | Lucide icons |
| `BSD-2-Clause.txt` | nginx |
| `BSD-3-Clause.txt` | uvicorn, psutil, MarkupSafe, click, idna, pycparser, python-dotenv, starlette |
| `MPL-2.0.txt` | ca-certificates |
| `PSF-2.0.txt` | Python, aiohappyeyeballs, typing_extensions, greenlet |
| `MIT-0.txt` | cffi |
| `Zlib.txt` | zlib |

Copyright notices for individual packages are retained in their package
metadata, in [../THIRD_PARTY_LICENSES/](../THIRD_PARTY_LICENSES/), and in the
upstream source distributions. If you redistribute a PullSpool image, keep
this directory, `THIRD_PARTY_LICENSES/`, and `THIRD_PARTY_NOTICES.md` with it.
